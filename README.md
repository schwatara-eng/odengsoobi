# drawing SOOBI

**그림 하나, 노래 하나.**

소수빈을 좋아하는 친구에게 선물하려고 만든 팬아트 전시 웹사이트입니다. 팬아트와 짧은 기록을 폴라로이드에 담고, 갤러리에서 작품과 함께 소수빈의 노래를 감상할 수 있도록 구성했습니다.

[전시 보러 가기](https://drawing-soobi.beigemango7.chatgpt.site/)

## 전시 구성

- **첫 화면**은 나무 책상 위에 팬아트 45장을 폴라로이드처럼 펼쳐 놓은 콜라주입니다.
- **갤러리**에서는 작품과 짧은 기록을 볼 수 있고, 영상이 연결된 작품은 YouTube 영상도 함께 재생할 수 있습니다.
- **작품 확대**는 첫 화면이나 갤러리에서 폴라로이드를 클릭하거나 터치하면 열립니다. 그림과 문구 전문을 볼 수 있습니다.
- **페이지 이동**은 상단 메뉴와 왼쪽 아래의 위·아래 버튼으로 할 수 있습니다.

## 사용 기술과 파일 구성

HTML, CSS, JavaScript로 제작하고 ChatGPT Sites로 배포했습니다.

| 파일 | 역할 |
| --- | --- |
| `index.html` | 첫 화면, 갤러리, 작품별 문구와 영상 |
| `style.css` | 폴라로이드 스타일과 화면 크기에 따른 레이아웃 |
| `script.js` | 첫 화면 사진 배치와 작품 확대 팝업 |
| `images/` | 팬아트 이미지와 배경 |

## 로컬에서 열기

저장소를 내려받고 `index.html`을 브라우저에서 열면 첫 화면과 갤러리를 볼 수 있습니다. VS Code에서는 Live Server로 열 수도 있습니다. YouTube 영상 재생에는 인터넷 연결이 필요합니다.
